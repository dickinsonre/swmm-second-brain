![ICM InfoWorks Simulation Parameters 100-Question Quiz and the Simulation Parameters Menu in ICM](https://media.licdn.com/mediaD4E12AQG7sq1fRlgNvQ "ICM InfoWorks Simulation Parameters 100-Question Quiz and the Simulation Parameters Menu in ICM")

I like or love vibe coding, as it lets me see the software I use in a different light. I normally use \#Replit and \#Lovable. Here is a lovable app that will work on your desktop or cell phone all about the simulation parameters for an ICM InfoWorks network. It was made by using Claude to read the online ICM Help file and make a JSON file of possible answers. I then looked at the JSON file and made a few corrections or deletions and then used Lovable to make the app using the JSON file. It is not as fast as it sounds, but it is pretty fast. You do have to go through a few publishing iterations.

Here is the link to the app—give it a whirl, and if you get bored, just click on "show me all of the answers," and you will see the right answers for all 100. I learned quite a lot from taking this app. It is pretty hard to answer most correctly—mainly as the possible answers are too close.
