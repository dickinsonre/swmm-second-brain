# Edition 34:  Misc Ruby Tools for ICM InfoWorks SWMM Modeling

![](https://media.licdn.com/dms/image/v2/D4E12AQHBow7-cAKBmw/series-logo_image-shrink_300_300/series-logo_image-shrink_300_300/0/1707065394509?e=1795651200&v=beta&t=tN-hhC1z9uquar5xA2f4iKHMUJauOcieSynf04B5KXc)

### EPASWMM5 Related Software Five decades with SWMM, still shipping code. SWMM5/6, ICM with Ruby, browser apps that teach the engines — and the art

![](https://media.licdn.com/mediaD4E12AQFwCrbFJbBoVA)

Edition 34 enhances InfoWorks ICM's capabilities by using Ruby to understand SWMM in ICM. InfoSewer and InfoSWMM tools make calibration files for ICM. Ruby will supplement ICM for shear stress and manage the user fields for nodes, links, and subcatchments. Unlike other editions, this revolves around InfoWorks ICM.

1.  InfoSWMM Subcatchment Management in ICM: Ruby scripts facilitate the transfer and management of SWMM subcatchment data within ICM, streamlining cross-platform workflows.

2.  AI-Powered PRN File Interpretation: Leveraging AI to translate ICM's PRN files into SWMM5-familiar formats, easing the transition for experienced SWMM5 users.

3.  User-Field Preservation Automation: Ruby scripts automate the export of user-defined fields to CSV, safeguarding valuable custom data across model iterations.

4.  Enhanced Shear Stress Calculations: Supplementing ICM's native QM capabilities with Ruby-based tools for more flexible Tau or shear stress computations.

5.  InfoSewer Steady State Report Analysis: A Ruby tool designed to parse and interpret steady-state reports from post-2025 InfoSewer models efficiently.

6.  Cross-Platform Data Visualization: Facilitating the creation of CSV files from InfoSewer or InfoSWMM for seamless integration with ICM's observed vs. predicted graphs.
