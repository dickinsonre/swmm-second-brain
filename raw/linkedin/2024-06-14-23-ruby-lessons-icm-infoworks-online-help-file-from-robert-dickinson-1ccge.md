The **InfoWorks ICM help file** now contains a new Technical Note that provides 23 lessons on using Ruby scripting. These lessons are designed to introduce users to the basics of Ruby programming and how to apply it within the context of InfoWorks ICM.

These lessons are presented progressively, starting with the fundamentals of Ruby programming and gradually introducing more advanced concepts and their application within the InfoWorks ICM environment. The lessons include sample scripts and explanations to help users understand the underlying concepts and how to apply them in their workflows.

The inclusion of these Ruby lessons in the InfoWorks ICM help file is a valuable addition. It provides users with a comprehensive resource to learn and enhance their scripting skills, enabling them to automate tasks, streamline workflows, and extend ICM's capabilities to meet their specific needs.
