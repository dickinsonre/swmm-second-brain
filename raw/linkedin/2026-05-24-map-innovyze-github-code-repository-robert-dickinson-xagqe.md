# Map of the Innovyze GitHub Code Repository

![Map of the Innovyze GitHub Code Repository](https://media.licdn.com/mediaD4E12AQFKMOKThPhdzw "Map of the Innovyze GitHub Code Repository")

### HTML view of the fantastic Autodesk Water Infrastructure Open Source Scripts

You are looking at an HTML view of the AWI GitHub, which has a lot of code on it. Ruby, SQL, things for ICM, WS Pro, InfoWater Pro, XPSWMM, InfoAsset Manage, ICM Live, and a lot of different software with varying history. What's different about this is that obviously you can go to GitHub and see all the files, but you just sort of see it as text, even though there are some nice README files. This view lets you see all the files and search them, so I have an idea of what does what.

> **This is better known as the Innovyze GitHub**

The innovyze/Open-Source-Support repo on GitHub holds the public Ruby, SQL, Python, and VBScript tooling for the Autodesk Water products: InfoWorks ICM, ICM SWMM, InfoAsset Manager, ICMLive, WS Pro, InfoWater Pro, and XPSWMM. Well over a thousand files across hundreds of nested folders. GitHub shows you all of it, but it shows it as text, one file at a time, and browsing that much is slow. With this many files, that stopped working for me. Plus, I love HTML, so I made an HTML viewer.

![](https://media.licdn.com/dms/image/v2/D4E12AQGdk04wJ7Mn5w/article-inline_image-shrink_1500_2232/B4EZ5b9PnOI0AU-/0/1779659243503?e=1795651200&v=beta&t=lSKlVVR7LJHZyiLiovOi4bkTRZGzney3d0RTi7S_o_I)

> **The Viewer Specs**

It flattens the whole repository into one searchable index you open in a browser. No install, no build, no server. As of today it maps 1,903 files across 455 folders, including 509 Ruby scripts and 142 SQL queries, with the counts running at the top of the page. There are even a few Ruby Exchange gems in there, new to ICM 2027. Note: This is made from a clone of the repository. I have to refresh it every week so it stays current with the AWI new commits

> **Here is what I hope it does**

- Full file tree. Every folder and file, expandable and collapsible in one view.

- Browse by product. Files are grouped by Autodesk Water product, so you jump straight to the ICM Ruby scripts, the InfoWater Pro tools, and so on.

- Inline preview. Click a file and read it without leaving the page. The source renders as text, readme.md renders as formatted Markdown, and screenshots display inline. I can look at the roughness. md file right next to the Ruby script that uses it.

- Search. Filter the tree by filename or path as you type.

- Direct GitHub links. Every entry links back to its source so you can open, fork, or copy the original.

- Export to CSV or Markdown for offline reference or pasting into other docs.

> **Open Source like almost all of my Apps**

The viewer is itself on GitHub, with a README, an index, and GitHub Pages. The live version runs as a Netlify app, and the README shows you how to get there. Everything I do, I try to put on GitHub, so this is no exception.
