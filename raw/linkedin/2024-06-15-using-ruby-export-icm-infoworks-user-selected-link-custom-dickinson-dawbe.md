# Using Ruby to Export ICM InfoWorks User-Selected Link Results to a Custom CSV Folder

![Using Ruby to Export ICM InfoWorks User-Selected Link Results to a Custom CSV Folder](https://media.licdn.com/mediaD4E12AQGZduzDJ0e-Vg "Using Ruby to Export ICM InfoWorks User-Selected Link Results to a Custom CSV Folder")

One of the true advantages of working with advanced water infrastructure modeling platforms like ICM InfoWorks is the ability to harness the flexibility of open-source scripting languages like Ruby. Our team has developed a unique Ruby script that allows users to seamlessly export their ICM InfoWorks link results to a custom CSV folder. It has a few notable features that set it apart.

First and foremost, this solution empowers users to selectively choose the specific data fields they wish to include in their CSV exports, ensuring that the output aligns perfectly with their analytical needs. By providing this level of customization, the script enhances productivity and streamlines workflows, allowing water professionals to focus on the insights that matter most.

However, the real power of this Ruby code lies in its ability to generate file names based on the selected result fields. Rather than relying on generic file names, the script creates intuitive, descriptive CSV files that make it easy to identify and access the data you require quickly. This attention to detail speaks volumes about the team's commitment to delivering solutions that elevate the user experience.

As with all our open-source offerings, this Ruby script is freely available for download from our GitHub repository. We encourage our community of water infrastructure modeling experts to utilize this tool and contribute their own enhancements and value-added features. By fostering a collaborative spirit, we can collectively push the boundaries of what's possible with ICM InfoWorks and unlock new levels of efficiency and innovation.
