# Ten Tips on using OPENAI, Claude.AI, Copilot, for ICM Ruby Code, SWMM5 C Code, SWMM5+ Fortran Code and 20 SWMM5 PDF Files

![Ten Tips on using OPENAI, Claude.AI, Copilot, for ICM Ruby Code, SWMM5 C Code, SWMM5+ Fortran Code and 20 SWMM5 PDF Files.](https://media.licdn.com/mediaD4E12AQGVfvdQNbjH1Q "Ten Tips on using OPENAI, Claude.AI, Copilot, for ICM Ruby Code, SWMM5 C Code, SWMM5+ Fortran Code and 20 SWMM5 PDF Files.")

Here’s a summary of the ten tips shared:

1.  [**Claude.AI**](http://Claude.AI) **for Ruby Exchange PDF from Autodesk Water**: Utilize [Claude.AI](http://Claude.AI) to read and query the Ruby Exchange PDF, uploaded on the ICM Information Hub, for coding questions related to Ruby. [Claude.AI](http://Claude.AI) comes in three versions: Opus, Sonnet, and Haiku.

2.  **OpenAI GPT for Ruby Exchange PDF from Autodesk Water**: Similar to the first tip, but involves creating a custom GPT, named ICM Ruby Wizard, which has the Exchange.PDF file pre-uploaded, eliminating the need for repeated uploads. Users can create their own GPTs, either private or public.

3.  **OpenAI for All SWMM Manuals in a Private GPT**: Expands upon Tip 2 by uploading and saving all SWMM5, SWMM4, and SWMM3 manuals to a private GPT, with a file limit of 20 PDFs, allowing for integrated queries across all manuals.

4.  **GitHub Copilot in Visual Studio Code for Ruby**: Facilitates coding in Ruby (and SQL) by providing real-time code suggestions as you write in Visual Studio Code, enhancing efficiency and accuracy.

5.  [**Claude.AI**](http://Claude.AI) **for GitHub Ruby Code in Concatenated Files**: To manage Ruby code exceeding 5000 lines, files were concatenated using DOS into smaller segments before uploading, due to [Claude.AI](http://Claude.AI)'s file size limitations.

6.  **OpenAI for GitHub Ruby Code in Concatenated Files**: It was observed that [Claude.AI](http://Claude.AI) could handle longer files than OpenAI, though this capability may vary over time.

7.  [**Claude.AI**](http://Claude.AI) **for Ruby File via Copy and Paste**: Suggests using [Claude.AI](http://Claude.AI) to read Ruby files by copying and pasting code directly into a prompt for analysis or queries.

8.  **OpenAI for Ruby File via Copy and Paste**: Similar to Tip 7, but utilizing OpenAI for processing Ruby code through direct copy-paste into a prompt.

9.  **GitHub Copilot in Visual Studio Code for SWMM5 C code**: Recommends using GitHub Copilot within Visual Studio Code for coding in SWMM5’s C language, pointing to the EPASWMM GitHub for reference.

10. **GitHub Copilot in Visual Studio Code for SWMM5+ code**: Further recommends GitHub Copilot for SWMM5+ code, specifically Intel Fortran code, with links provided on [CIMM.ORG](http://CIMM.ORG).

A bit of history about 1729: It's famously known as the Hardy-Ramanujan number after a story involving two great mathematicians, G.H. Hardy and Srinivasa Ramanujan. According to the anecdote, Hardy visited Ramanujan in the hospital and mentioned that he arrived in a taxi numbered 1729, which he found to be a rather uninteresting number. Ramanujan immediately responded that 1729 is actually very interesting because it is the smallest number expressible as the sum of two cubes in two different ways: 1729=1^3+12^3=9^3+10^3. This property makes 1729 a significant figure in the world of mathematics, showcasing Ramanujan's extraordinary intuitive grasp of numbers.
