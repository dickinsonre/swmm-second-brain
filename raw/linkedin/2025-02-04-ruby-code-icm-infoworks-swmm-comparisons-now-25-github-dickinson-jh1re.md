# Ruby Code for ICM InfoWorks and ICM SWMM Comparisons is now in 25 Folders on the Innovyze GitHub

![Ruby Code for ICM InfoWorks and ICM SWMM Comparisons is now in 25 Folders on the Innovyze GitHub](https://media.licdn.com/mediaD4E12AQE8NiL68DksZg "Ruby Code for ICM InfoWorks and ICM SWMM Comparisons is now in 25 Folders on the Innovyze GitHub")

There is a completely reorganized suite of Ruby code on the [Innovyze GitHub Website](https://github.com/innovyze/Open-Source-Support/tree/main/01%20InfoWorks%20ICM/01%20Ruby/02%20SWMM). The number of folders went from 155 to 25 but the number of Ruby .rb files is still around 250. Obviously, there is more than one rb file in a folder now, but hopefully the files are easier to find. There are a few overriding goals of this code. Supply tools for comparing ICM SWMM to InfoSWMM, ICM InfoWorks to InfoSewer, ICM InfoWorks to ICM SWMM and SWMM5, ICM InfoWorks to Design Equations, Import and Export, Sensitivity, and Geoplan Tools.
