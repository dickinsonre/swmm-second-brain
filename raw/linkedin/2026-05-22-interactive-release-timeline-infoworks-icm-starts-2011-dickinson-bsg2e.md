# Interactive Release Timeline for InfoWorks ICM Starts in 2011 and Lasts Forever

![](https://media.licdn.com/mediaD4E12AQEiDPvw9XsCfQ)

### I built an interactive release timeline for InfoWorks ICM. Here is what it does and why.

> **My Reason**

The "What's New" notes in the ICM help file are scattered across years of releases. Useful information, but hard to navigate and, more importantly, hard to do version comparisons. So I turned the entire What's New into an interactive app you can explore on your browser and cell phone.

> **It does a few things.**

It is a release timeline from every ICM version, so you can see what was added and when. Ask it "what ICM feature was added in 2012?" and you get an answer. Ask what changed in a specific feature between 2012 and 2027, and you can trace it across releases.

> **There is a version compare view.**

Pick two versions and see the differences side by side.

![](https://media.licdn.com/dms/image/v2/D4E12AQEwB-AZG8pT8Q/article-inline_image-shrink_1500_2232/B4EZ5RjFw2JkAU-/0/1779484614064?e=1795651200&v=beta&t=KbMzslniLr2UigAiDUXBR8sZMfoJW9yPanRBSfyT-Kg)

It has an AI assistant built in, so you can ask questions in plain language instead of scrolling through release notes hunting for a keyword.

![](https://media.licdn.com/dms/image/v2/D4E12AQGZLfievE5V_Q/article-inline_image-shrink_1500_2232/B4EZ5RjJEdIIAQ-/0/1779484627496?e=1795651200&v=beta&t=ldg4avXyDQihkQ6U6c1Chv9t5wof5VCM_mGTdB7oo40)

It includes interactive guidelines for the modeling concepts behind the features. 2D meshing, roughness characteristics, and more. You can click through and actually understand.

![](https://media.licdn.com/dms/image/v2/D4E12AQE7L77hu_czJA/article-inline_image-shrink_1500_2232/B4EZ5RjZoIH8AQ-/0/1779484695367?e=1795651200&v=beta&t=Jx4oXTJTzQls4-GI0GBrSp-GxkGSCRNsdF1TLR_27ks)

> **Maps of the 800+ New Features in ICM.**

It maps how the database architecture has changed over time, from the older workgroup model to today's cloud and database setup. If you have ever wondered how ICM's data structure evolved, it is laid out here.

![](https://media.licdn.com/dms/image/v2/D4E12AQE_k0_jGd7wdg/article-inline_image-shrink_1500_2232/B4EZ5RjzJKIwAU-/0/1779484799862?e=1795651200&v=beta&t=2vVmEwERKgbArK7RTK66rZ1bEL4dyWebXMFIcEKAyBo)

> **I did this as it helps me understand ICM.**

This is my own work. It is not an Autodesk product, and it is not affiliated with the ICM team. I built it, as I have a long connection with Innovyze and Autodesk, and I am genuinely glad to use and understand ICM.

Building apps is how I learn software. This one taught me the history of ICM. That is the real reason it exists.

The code is on GitHub, like almost everything I do. Take it apart, see how it works, and build your own version: [https://github.com/SWMMEnablement/ICMNewView](https://github.com/SWMMEnablement/ICMNewView)

Whether you are new to ICM or have years of ICM experience, this gives you a faster way to find features, compare versions, and understand the concepts underneath—and it is fully shareable and visual.

Try it: [https://icm-new-view-robertdickinson.replit.app](https://icm-new-view-robertdickinson.replit.app)
