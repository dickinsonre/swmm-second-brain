# InfoSewer Load Allocation Expertise: Test Yourself with 50 Questions for 2025 to 2050

![](https://media.licdn.com/mediaD4E12AQECaGZipbvf0A)

Here are the 50 multiple-choice questions based on the infoSewer help file about Innovyze's DWF Allocator, designed to test understanding of its features and functionalities.

**1. What does DWF stand for in the context of sewer modeling?**

A. Daily Wastewater Flow

B. Design Wastewater Factor

C. Dry Weather Flow

D. Distributed Water Flow

**Answer: C. Dry Weather Flow**

**2. Which of these is NOT a method for allocating loads in InfoSWMM DWF Allocator?**

A. Polygon Intersection

B. Closest Junction

C. Rainfall-Derived Infiltration

D. Meter-Conduit Allocation

**Answer: C. Rainfall-Derived Infiltration**

**3. The Polygon Intersection method requires which two types of polygon layers?**

A. Primary and Secondary

B. Primary and Intersected

C. Secondary and Intersected

D. Primary and Thiessen

**Answer: A. Primary and Secondary**

**4. What is the purpose of the Primary polygon layer in methods like Polygon Intersection?**

A. To represent land use or zoning

B. To represent the area contributing DWF to individual nodes

C. To store the results of intersecting Primary and Secondary layers

D. To define the outer boundary for Thiessen polygon creation

**Answer: B. To represent the area contributing DWF to individual nodes**

**5. What does the Secondary polygon layer typically represent in the Polygon Intersection method?**

A. Load area contributing to each node

B. Customer meter locations

C. Land use, zoning, or other usage classifications

D. Pre-intersected polygon data

**Answer: C. Land use, zoning, or other usage classifications**

**6. Which method uses spatial summation of consumption category area polygons?**

A. Polygon Intersection

B. Meter Summation

C. Polygon Extraction

D. Closest Link

**Answer: C. Polygon Extraction**

**7. The Meter Summation method requires which type of data input?**

A. Land use polygons

B. Zoning classifications

C. Customer/meter billing data

D. Thiessen polygons

**Answer: C. Customer/meter billing data**

**8. What is the purpose of the "Closest Junction" method?**

A. To allocate loads based on polygon intersections

B. To assign loads to the junction closest to a water meter

C. To manually assign meters to junctions

D. To calculate loads based on land use

**Answer: B. To assign loads to the junction closest to a water meter**

**9. The "Closest Link" method assigns meter loads to which of the following?**

A. The closest upstream or downstream nodes of a link

B. The closest junction

C. The center point of the closest link

D. The furthest junction from the meter

**Answer: A. The closest upstream or downstream nodes of a link**

**10. Which methods allow for user-defined meter allocation?**

A. Meter-Manhole Allocation and Meter-Link Allocation

B. Closest Junction and Closest Link

C. Polygon Intersection and Polygon Extraction

D. Meter Summation and Polygon Extraction

**Answer: A. Meter-Manhole Allocation and Meter-Link Allocation**

**11. What is the purpose of the "Meter Assignment" dialog box?**

A. To register polygon layers

B. To define load factors

C. To graphically assign meters to specific nodes or links

D. To create Thiessen polygons

**Answer: C. To graphically assign meters to specific nodes or links**

**12. What does the "Allocation Scaling Factor" do?**

A. Scales the size of polygons

B. Normalizes demand data, often used for unit conversion

C. Adjusts the load factors for each usage type

D. Determines the distance weighting for load allocation

**Answer: B. Normalizes demand data, often used for unit conversion**

**13. What is the function of the "Load Factor Developer"?**

A. To automatically generate a list of unique usage types

B. To calculate load factors based on spatially located loads and land use boundaries

C. To manually adjust load factors

D. To create new fields in the polygon layer database

**Answer: B. To calculate load factors based on spatially located loads and land use boundaries**

**14. What is the purpose of creating Thiessen polygons in DWF allocation?**

A. To define land use classifications

B. To create load area polygons based on the proximity to nodes

C. To graphically assign meters to junctions

D. To intersect primary and secondary layers

**Answer: B. To create load area polygons based on the proximity to nodes**

**15. Which tool is used to register polygon layers for use in allocation methods?**

A. Allocation Manager

B. Polygon Layer Registration

C. Load Factor Calculator

D. Meter Assignment

**Answer: B. Polygon Layer Registration**

**16. What are the three polygon layer types that can be registered?**

A. Primary, Secondary, Tertiary

B. Primary, Secondary, Intersected

C. Input, Output, Intersected

D. Land Use, Zoning, Load Area

**Answer: B. Primary, Secondary, Intersected**

**17. What does the "Overwrite Existing Load When Allocating DWF Allocator" option do?**

A. Replaces existing Manhole IDs

B. Adds computed loads to existing Manhole loads

C. Replaces existing Manhole loads with newly computed loads

D. Distributes loads evenly among Manholes

**Answer: C. Replaces existing Manhole loads with newly computed loads**

**18. What is the purpose of the "Usage Data" tab in the Allocation Methods?**

A. To define meter data

B. To specify the allocation method

C. To set up the tool to allocate DWF based on usage type and load factors

D. To register polygon layers

**Answer: C. To set up the tool to allocate DWF based on usage type and load factors**

**19. What does the "Check Usage Type" button do in the Usage Data table?**

A. Verifies the accuracy of load calculations

B. Automatically loads unique usage types from the registered secondary polygon layer

C. Checks for errors in the polygon data

D. Calculates the total load for each usage type

**Answer: B. Automatically loads unique usage types from the registered secondary polygon layer**

**20. What is a typical application of adding a "secondary" layer in Polygon Intersection method?**

A. Phasing of Development

B. Adding Water Meter Data

C. Defining Load Area Polygons

D. Defining Thiessen Polygons

**Answer: A. Phasing of Development**

**21. What does the option "Distribute Allocated DWF Automatically" do?**

A. Evenly distributes loads to all manholes within a polygon

B. Allocates loads based on distance weighting

C. Assigns loads to the closest manhole

D. Overwrites existing loads

**Answer: A. Evenly distributes loads to all manholes within a polygon**

**22. Which field in the Secondary Layer is used in the Build Out Ratio option of Polygon Intersection Method?**

A. Population

B. Load Factor

C. Ratio of developed land to total land

D. Usage Type

**Answer: C. Ratio of developed land to total land**

**23. The "Convex Hull" technique for creating Thiessen polygons defines the outer boundary based on what?**

A. User-drawn polygon

B. An imaginary "rubber band" around all Manholes

C. A selected background layer

D. A predefined boundary file

**Answer: B. An imaginary "rubber band" around all Manholes**

**24. What is the purpose of the "Load Factor Calculator"?**

A. To define load factors for different usage types

B. To calculate the total area of polygons

C. To adjust load factors to match a known total system load

D. To assign meters to junctions

**Answer: C. To adjust load factors to match a known total system load**

**25. What does the "Purge IDs" button do in the Meter Summation method?**

A. Removes all IDs from the corresponding database field

B. Creates a new ID field

C. Purges invalid meter data

D. Deletes selected polygons

**Answer: A. Removes all IDs from the corresponding database field**

**26. Which method is recommended as a starting point for the Meter-Link Allocation tool?**

A. Closest Junction

B. Meter Summation

C. Polygon Extraction

D. Closest Link

**Answer: D. Closest Link**

**27. What are the options for allocating meter demands to upstream and downstream Manholes in the Closest Link and Meter-Link methods?**

A. Evenly Divided, Closest Manhole, Furthest Manhole

B. Evenly Divided, Distance Weighted, Closest Manhole, Furthest Manhole

C. Distance Weighted, Closest Manhole, Furthest Manhole

D. Evenly Divided, Distance Weighted, Closest Manhole

**Answer: B. Evenly Divided, Distance Weighted, Closest Manhole, Furthest Manhole**

**28. What is the purpose of the "Allocate RDII" tool?**

A. To calculate Rainfall-Derived Infiltration and Inflow

B. To allocate Dry Weather Flow

C. To assign meters to junctions

D. To define load factors

**Answer: A. To calculate Rainfall-Derived Infiltration and Inflow**

**29. What must be specified for each sewershed polygon when using the "Allocate RDII" tool?**

A. UH Group ID and receiving Junction ID

B. Land use type and load factor

C. Meter ID and flow rate

D. Polygon area and population

**Answer: A. UH Group ID and receiving Junction ID**

**30. What does the "Area Scaling Factor" typically used for in the "Allocate RDII" tool?**

A. Unit conversions (e.g., map units to acres)

B. Adjusting load factors

C. Defining the buffering percentage for Thiessen polygons

D. Normalizing demand data

**Answer: A. Unit conversions (e.g., map units to acres)**

**31. What does the "Draw Sewershed-Jnt Linkage" button do in the "Allocate RDII" tool?**

A. Creates permanent links between sewersheds and junctions

B. Draws temporary graphical representations from sewershed centers to receiving nodes

C. Calculates the distance between sewersheds and junctions

D. Defines the flow path for RDII

**Answer: B. Draws temporary graphical representations from sewershed centers to receiving nodes**

**32. What is the purpose of the "Import Meter Data" icon?**

A. To import land use data

B. To import polygon layers

C. To convert a text file with meter data into a point shapefile

D. To import load factors

**Answer: C. To convert a text file with meter data into a point shapefile**

**33. Which of these tools is NOT used for polygon editing?**

A. Split Polygon

B. Union

C. Intersect

D. Append Row

**Answer: D. Append Row**

**34. What is the purpose of the "Assign Contributing Polygon" tool?**

A. To automatically assign junction IDs to polygons

B. To manually assign a junction ID to selected contributing polygon(s)

C. To create Thiessen polygons

D. To define load factors

**Answer: B. To manually assign a junction ID to selected contributing polygon(s)**

**35. What does the "Add Loading Junctions to Domain" tool do?**

A. Adds all junctions to the current domain

B. Adds junctions with assigned contributing polygons to the current domain

C. Adds selected junctions to the domain

D. Removes junctions from the domain

**Answer: B. Adds junctions with assigned contributing polygons to the current domain**

**36. What file format does the "Load" command in the Usage Data options typically use?**

A. .txt

B. .shp

C. .wdf

D. .csv

**Answer: C. .wdf**

**37. What does the "Default Load/Coverage Field" in the Usage Data table define?**

A. The field where loads will be stored

B. The field for usage types

C. The field for any load without an assigned usage type and corresponding Load/Coverage field

D. The field for load factors

**Answer: C. The field for any load without an assigned usage type and corresponding Load/Coverage field**

**38. What is the purpose of the "Target DWF Allocator Set" in the Options dialog?**

A. To define the current scenario

B. To select a different DWF Allocator set than the currently active scenario's DWF Allocator set

C. To create a new DWF Allocator set

D. Both B and C

**Answer: D. Both B and C**

**39. What units are commonly used for Load Factors when dealing with area-based calculations?**

A. gpm/person

B. Lps/hectare

C. gpm/acre

D. cfs/mile

**Answer: C. gpm/acre**

**40. What is a common reason for applying an Allocation Scaling Factor of 1/43560?**

A. To convert square feet to acres

B. To convert acres to square feet

C. To convert gallons per minute to liters per second

D. To convert cubic feet per second to gallons per minute

**41. What does the "New Field" button allow the user to do in various dialog boxes?**

A. Create a new polygon layer

B. Create a new field in the corresponding layer's database

C. Create a new meter layer

D. Create a new usage type

**Answer: B. Create a new field in the corresponding layer's database**

**42. What is the "Auto Junction Assignment" feature used for in the context of Thiessen Polygon creation?**

A. To automatically assign land use types

B. To automatically assign the first encountered junction ID within each polygon

C. To automatically calculate load factors

D. To automatically assign meters to junctions

**Answer: B. To automatically assign the first encountered junction ID within each polygon**

**43. What is the purpose of the "Block Edit" button in the Usage Data table?**

A. To edit multiple cells in a column simultaneously

B. To delete a block of rows

C. To insert a block of rows

D. To sort a block of data

**Answer: A. To edit multiple cells in a column simultaneously**

**44. The "Closest Manhole" method is most similar to which other allocation method?**

A. Polygon Intersection

B. Polygon Extraction

C. Meter-Manhole Allocation

D. Meter-Link Allocation

**Answer: C. Meter-Manhole Allocation**

**45. Which of these is a suggested step in the "Quick Start Tutorial" for verifying results after running the DWF Allocator with the "Polygon Intersection" method?**

A. Checking that the total system flow is approximately 1.7 cfs

B. Checking that the total system flow is approximately 1.4 cfs

C. Checking that the total system flow is approximately 2.0 cfs

D. Checking that the total system flow is approximately 0.5 cfs

**46. Which of the following is NOT one of the seven automated geospatial methods for computing and loading network models offered by InfoSWMM DWF Allocator?**

**47. What is the primary purpose of using GIS technology in InfoSWMM DWF Allocator?**

**48. According to the introduction by the Innovyze CEO, what is a key element of sanitary and combined sewer collection modeling?**
