> What is the IWR file?

1.  **IWR File Definition**: The IWR file is a results file generated by the SWMM (Storm Water Management Model) and SIM (Simulation) engines. This file contains the output data from simulations run using these engines.

2.  **Ruby's Role**: Ruby, a programming language used it the ICM UX, is being utilized to read and process data from two different IWR files. These files are associated with different engines:**SWMM IWR File**: Named "IWSWSIM", this IWR file is specifically for results from the SWMM engine.**SIM IWR File**: This file is associated with the InfoWorks Simulation engine and its filenames begin with "SIM".

3.  **Accessing IWR Files**: To view these IWR files, you can navigate through the software interface. Here's how:Go to the "Tools" [menu.Select](http://menu.Select) "Options".In the Options menu, find and click on "Local Folders".Within Local Folders, look for and click on "Results".

In this "Results" section, you'll find the IWR files generated by the respective engines. These files can then be accessed and read using Ruby for further analysis or processing after dragging the model run to the Geoplan or opening it.
