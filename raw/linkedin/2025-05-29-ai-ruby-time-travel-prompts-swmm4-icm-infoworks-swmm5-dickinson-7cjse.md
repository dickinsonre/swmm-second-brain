Edition 45 - As an Autodesk technologist passionate about stormwater and flood modeling, I’m excited to share insights from a series of articles exploring innovative ways to leverage AI and Ruby or Python scripting to enhance hydraulic modeling in InfoWorks ICM and SWMM5. What I am trying to show here is no matter how far in the past or an assumed future—as long as the data or model is text and there are some comments about the format in the file, you can use the current AI and certainly the future AI tools to help you understand what is going on. Here are the topics covered.

1.  **Reviving Legacy Models**: Imagine 2030, with ArcMap and InfoSewer retired. A Ruby script, inspired by Stellar Solution Engineer Tim Medearis, reads historic InfoSewer RPT outputs for seamless integration into ICM InfoWorks, bridging decades of data (Article 1).

2.  **AI-Powered SWMM4 to SWMM5 Conversion**: Using AI to convert 1988 SWMM4 models to SWMM5, I demonstrate how understanding both formats enables a smooth transition, preserving legacy models with modern capabilities (Article 2).

3.  **Unit Conversion for ICM PRN Files**: I tackle InfoWorks ICM’s SI-only PRN file limitation by using AI to convert outputs to CFS units, enhancing flexibility for SWMM5 users (Article 3).

4.  **AI-Driven SWMM5 Input File Creation**: A two-prompt AI strategy streamlines the generation of complete, accurate SWMM5 input files from SWMM5 rules, saving time and reducing errors (Article 4).

5.  **AI Tools for Code Analysis**: I share ten tips for using OpenAI, Claude AI, and GitHub Copilot to understand and explain Ruby, C, and Fortran code for ICM and SWMM5, including analyzing 20 SWMM5 PDF documents (Article 5).

6.  **Decoding 1988 SWMM4 Code**: With ChatGPT, I revisit my 1988 SWMM4 code, identifying a customized Richardson extrapolation, showcasing AI’s ability to interpret legacy programming (Article 6).

7.  **Interpreting ICM PRN Files for SWMM5 Users**: AI helps SWMM5 users understand ICM InfoWorks PRN files, drawing on my 1978 experience with detailed table outputs to extract critical insights (Article 7).
