### Preserving SWMM's Legacy: A Digital Accessibility Initiative

I've undertaken a project to make the historical Storm Water Management Model (SWMM) documentation more accessible to engineers, researchers, and practitioners worldwide. Starting with the original National Technical Information Service (NTIS) documents, I've carefully processed the documentation spanning all five major SWMM versions.

The digitization process involved splitting and compressing the PDF files using Adobe's tools while maintaining document fidelity. To ensure widespread access, I've created a dual-platform distribution approach: the documents are hosted on LinkedIn (accommodating their 300-page document limit) and mirrored on GitHub for comprehensive access.

This initiative serves multiple purposes. Beyond preservation, it makes these foundational hydraulic modeling documents more discoverable to LinkedIn's professional network. The optimized format also enables modern AI systems to better analyze and query the technical content, despite their inherent token and page limitations.

Edition 36 now encompasses the complete documentation set for SWMM versions 1 through 5, representing decades of hydrologic and hydraulic modeling evolution. By bridging these historical documents into the digital age, we're ensuring that the theoretical foundations and practical insights of SWMM remain accessible for future generations of water resources engineers. Note: The SWMM5 file is the QA/QC EPA document comparing SWMM4 to SWMM5 for these mostly classic Extran3 and Extran4 files.

Counting the SWMM4 test files used in this QA testing document. The files were divided into three distinct categories:1. Extran Manual Test Cases: 10 files (EXTRAN1 through EXTRAN10), which were mostly from SWMM3.

2\. Challenge Test Cases: 5 files (TEST1 through TEST5) added for SWMM5 from SWMM43. User-Supplied Test Cases: 5 files (USER1 through USER5) added for SWMM5 from SWMM4

In total, 20 SWMM4 test files were used to validate SWMM5 against SWMM4. These files covered a wide range of scenarios, from simple networks to complex real-world systems. Each test case was carefully selected to evaluate different aspects of the software's dynamic wave flow routing capabilities.The document mentions that all these test files are available electronically at the EPA SWMM website, where each test case includes the SWMM4 Extran input file (with .dat extension), and for the user-supplied cases, the corresponding SWMM4 Runoff input file as well.
