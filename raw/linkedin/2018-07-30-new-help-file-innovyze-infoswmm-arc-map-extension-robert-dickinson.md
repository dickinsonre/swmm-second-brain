# New Help file for Innovyze InfoSWMM (InfoSWMM is an Arc Map Extension)

![](https://media.licdn.com/mediaC4E12AQFN86IrvXg_qg)

The new help file for Innovyze InfoSWMM is based on the menu structure. I think it helps connect the tools, data, editing and great InfoSWMM features in an easier to understand help. Here are main components of the Help Menu. This was a significant change to the format for the InfoSWMM, InfoSewer and InfoSWMM SA help files. The help file is now organized by Menu or Ribbon Category with a Top menu showing the major categories. This means for example, all DB help files are associated with the Edit Menu. All Run Manager topics are associated with the tools.  Hopefully, this make each file easy to see and navigate.
