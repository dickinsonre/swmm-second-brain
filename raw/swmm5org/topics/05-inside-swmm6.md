Inside SWMM6

*OpenSWMM 6 from the source code up: new solvers, 2D, plugins and the GUI.*

OpenSWMM 6 is the open successor to EPA SWMM5, built by Caleb Buahin and the OpenSWMM team at HydroCouple. I don’t write the engine. I build apps that open it up, run it next to SWMM5 and show what is new.

Start here

- [**The Road to SWMM6**](https://swmm5.org/#road-to-swmm6). SWMM 6.0 alpha, SWMM5+ at CIMM and the open lineage.

- [**Nesterov Gradient Optimizer for SWMM6 and SWMM5**](https://swmm5.org/2026/07/26/nesterov-gradient-optimizer-for-swmm6-and-swmm5/). A faster iteration, tested in both engines.

- [**From a SWMM5 or SWMM6 Model Set to a Finished PDF Report**](https://swmm5.org/2026/10/18/1-what-the-wizard-does/). One wizard for either engine.

Try a tool

- [**SWMM6 UX Explorer**](https://swmm6-ux-explorer.netlify.app/). The OpenSWMM 6 desktop workspace, recreated as one web page around a demo model.

- [**Inside the SWMM6 GUI**](https://inside-swmm6-gui.netlify.app/). How the SWMM6 GUI (Qt6, C++20) is put together.

- [**OpenSWMM Finite Volume**](https://openswmm-finite-volume.netlify.app/). OpenSWMM 6’s finite-volume solver, explained.

More apps on this topic

- [**Two Tables, One Pipe**](https://two-tables-one-pipe-swmm6-corinne.netlify.app/). Companion to Corinne Wiesner-Friedman’s article on exact cross-section geometry for OpenSWMM 6.

- [**SWMM6 and ANUGA 2D**](https://swmm6-anugua-2d.netlify.app/). ANUGA Hydro as a 2D partner for SWMM6.
