Topics

More than fifty years of SWMM, organized six ways. Pick the question you have. Each topic page gives you posts to read, apps to try, an example to work through and the code behind it.

The order runs from where SWMM came from, through the inside of SWMM5, to ICM, to SWMM6, and ends with how to compare all of them with AI.

[1. SWMM History: SWMM1 to SWMM6](https://swmm5.org/topics/swmm-history/)

*The engines from 1971 to now, rebuilt and running in your browser.*

Start with [History of SWMM 1, 2, 3, 4, 5 to the Year 2015](https://swmm5.org/2015/07/22/history-of-swmm-to-the-year-2015/). Try [SWMM 1 Engine](https://swmm1-engine-imports-swmm5.netlify.app/).

[2. Inside SWMM5](https://swmm5.org/topics/inside-swmm5/)

*How EPA SWMM 5.2.4 computes runoff, routing and everything between, one app at a time.*

Start with [Hydraulic Jump, Froude Number and \#INSIDE_SWMM5](https://swmm5.org/2017/07/01/froude-number-and-inside_swmm5/). Try [Inside SWMM](https://inside-swmm.netlify.app/).

[3. SWMM5 and ICM InfoWorks](https://swmm5.org/topics/swmm5-and-icm/)

*The same network in two engines, with the Ruby scripts and apps that compare them.*

Start with [Getting Started with Ruby Scripting for InfoWorks](https://swmm5.org/2025/04/09/getting-started-with-ruby-scripting-for-infoworks/). Try [ICMT Explorer for SWMM](https://icmt-explorer-for-swmm.netlify.app/).

[4. ICM InfoWorks and SWMM6](https://swmm5.org/topics/icm-and-swmm6/)

*Where OpenSWMM 6 meets ICM, and where they part ways.*

Start with [How the Control Section Lab Works](https://swmm5.org/2026/10/18/how-the-control-section-lab-works-a-reference-solver-two-swmm-engines-and-the-infoworks-icm-rules/). Try [SWMM and ICM Control Section Lab](https://swmm-icm-control-section-lab.netlify.app/).

[5. Inside SWMM6](https://swmm5.org/topics/inside-swmm6/)

*OpenSWMM 6 from the source code up: new solvers, 2D, plugins and the GUI.*

Start with [The Road to SWMM6](https://swmm5.org/#road-to-swmm6). Try [SWMM6 UX Explorer](https://swmm6-ux-explorer.netlify.app/).

[6. Comparing Models with AI](https://swmm5.org/topics/ai-model-comparison/)

*How to use AI to run, check and compare engines without fooling yourself.*

Start with [The Vibe Coding Paradox](https://swmm5.org/2026/07/08/the-vibe-coding-paradox-what-happens-when-a-50-year-swmm-expert-gets-ai-superpowers/). Try [Agreement Is the Null](https://engine-ageement-is-the-null.netlify.app/).
