# InfoSewer Exchange in Motion: the 0060 InfoSewer to ICM importer under ICM Exchange, played in eight scenes

## In three points
- **What:** README_Exchange.md in a form you can watch. The README explains how five files let Autodesk's 0060 InfoSewer to InfoWorks ICM toolkit run under ICM Exchange from a command line with no dialogs; the Play tab acts that out in eight scenes and 63 steps (files dropped into the toolkit folder, three swaps for the network, configuration and scenarios, and confirmations, one model through the pipeline, a folder of models unattended, the one call to confirm on your ICM version, and what the engine does not carry). The README tab holds the complete original text.
- **So what:** Scene text, code lines and line numbers come from the README and the four script files as supplied on 10 November 2026; the two things on the Play tab that are not from a live ICM run are labelled where they appear (the Scene 5 console shows the script's own messages with counts left as dots). The harness was checked on Linux under Ruby 3.3.6: a syntax check, a stubbed batch run and six runs of the scenario function.
- **Now what:** Use it to understand the harness before trying it. No InfoWorks ICM was available: the harness has not converted a model, and nobody has run it against a live ICM.

This summary was written after the fact. The page ships no technical summary of its own. Its version and date are the page's own ("v1.0 · 2026-11-10"). The file name above is ours. Every number below is copied from the page. Nothing was run to write this file.

## What it does

Tabs: Play, README, About, Doc. Space plays and pauses, arrow keys step, [ and ] change scene, and the scene list jumps; with reduced motion requested the page does not autoplay. Copy README.md puts the README on the clipboard.
