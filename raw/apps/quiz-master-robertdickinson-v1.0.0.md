# SWMM5 Quizzer: A browser quiz app for EPA SWMM learning

## What it does

SWMM5 Quizzer presents multiple-choice questions about EPA's Storm Water Management Model. Learners can choose practice or timed quiz modes, review answers and explanations, and view topic diagrams. A separate Simulation Quiz presents drainage-network scenarios and questions about saved hydraulic results. The app outputs quiz scores, explanations, elapsed time, diagrams, and scenario results; it does not run the EPA SWMM engine.

## How it computes

- `client/src/components/QuizContainer.tsx`, `QuizContainer`: shuffles the question array with `Math.random()` and takes the first 25 questions (`client/src/components/QuizContainer.tsx:29-34`). `handleSubmit` counts answers that match each question's stored answer. The timer calculates elapsed seconds from `Date.now()` and formats minutes and seconds.
- `client/src/pages/SimulationQuiz.tsx`, `startSimulation`: selects a stored scenario through `getRandomScenario` in `client/src/data/simulations.ts`, then advances the screen through timed display phases. `handleAnswer` compares the selected option index with the stored `correctAnswer` and increments the score.
- Hydraulic results, scenario questions, answers, explanations, and diagram descriptions are data in `client/src/data/`. No SWMM engine invocation or hydraulic calculation function was found in the checked app source.

## Inputs and outputs

- Browser input: selected quiz mode, optional category URL, and selected answer choices.
- Browser output: quiz questions, score, answer feedback, explanations, diagrams, elapsed time, and saved scenario result summaries.
- Frontend routes are `/`, `/quiz`, `/quiz/:category`, `/simulation-quiz`, and `/docs` (`client/src/App.tsx:13-22`).
- The server defines `POST /api/quiz/submit` and `GET /api/quiz/attempts` (`server/routes.ts:7-32`). Attempts are held in process memory by `MemStorage` (`server/storage.ts:11-62`). The checked frontend source does not call these endpoints.
- The Drizzle schema declares `users` and `quiz_attempts` (`shared/schema.ts:5-25`), but the runtime storage implementation is in-memory. No user file import or export was found.
- Published URLs observed: `https://swmm5quiz.com` and `https://quiz-master-robertdickinson.replit.app`. The configured Git remote is listed in the front matter.
