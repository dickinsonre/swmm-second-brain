Bob's Replit app Hindsight Prophet: an app that answers technical and strategic questions about stormwater models by sending each question to a council of AI personas and returning their analyses, a consensus and a roadmap. Version 1.0.0, at `hindsight-prophet-robertdickinson.replit.app` [S121](../sources/S121-hindsight-prophet-replit-summary.md).

**A caution about its source.** Everything on this page rests on [S121](../sources/S121-hindsight-prophet-replit-summary.md), which Replit Agent wrote on 15 November 2026 from the project's source. Nothing here has been read by Bob (Q74).

**What the summary says** [S121](../sources/S121-hindsight-prophet-replit-summary.md)
- No simulation engine is called. SWMM and ICM are advisory context, read from pasted text by regular expressions. `engines: none`.
- Persona requests go through the OpenAI SDK to OpenRouter's `google/gemini-2.5-pro`. Standard mode uses 4 personas; full mode adds 2.
- Persona requests use temperature 0.7 and a 4,000-token output limit; the synthesis request uses 0.7 and 8,000.
- The display score maps HIGH to 90, MEDIUM or missing to 60 and LOW to 30 and averages them. The file calls it a heuristic, not a calibrated probability.
- References are generated by the language model and are not independently verified.
- Summaries of the latest 3 stored consultations are added to each prompt. This is shared database history, not history filtered by user.
- The development API reported 12 stored consultations.
- `npm run check` passed. `npm test` has no test script. Four HTTP reads returned 200. No consultation was submitted.
- The stats endpoint returns a zero count if storage fails, which can hide a database error. The exported report carries a hardcoded site address different from the deployment address.

**What it does not show.** Live AI generation, output quality and citation accuracy were not checked. Database writes, authorization and rate limits were not checked. No production build. No engineering review of the generated advice. [S121](../sources/S121-hindsight-prophet-replit-summary.md)
