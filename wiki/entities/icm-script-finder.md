A search page for the InfoWorks ICM community scripts: https://mel-meng.github.io/github_search/ [S383](../sources/S383-note-icm-script-finder-link.md). Bob asked for it to be linked from the wiki on 19 November 2026 [S383](../sources/S383-note-icm-script-finder-link.md).

**What it does, as Claude read it on 19 November 2026** [S383](../sources/S383-note-icm-script-finder-link.md). Its title is "ICM Script Finder", branded "Autodesk Water · Community scripts". It searches keywords and README text across the scripts, queries, models and workflows in the "01 InfoWorks ICM" folder of innovyze/Open-Source-Support, filters them by Ruby, SQL, Python or Other, and opens each result's README and source. It names no author and states no counts, date or version; it sits on the GitHub Pages host of the GitHub user mel-meng.

**The repository it searches.** innovyze/Open-Source-Support, Autodesk's public example repository, held 532 .rb files and 96,652 lines at commit c580601 (2026-10-20), by the count of [ICM Exchange 2026](icm-exchange-2026.md) [S244](../sources/S244-icm-exchange-2026-summary.md).

**Its own caution** [S383](../sources/S383-note-icm-script-finder-link.md): "Community scripts are provided in the source repository. Review each script before using it in a model."
