**What it is.** The technical summary that ships with the SWMM & ICM Knowledge Library, artifact v70: one searchable HTML file of Bob's published work on SWMM3 through SWMM6, InfoWorks ICM, InfoSWMM, InfoSewer and XPSWMM. Raw file: [raw/apps/swmm-icm-knowledge-library.md](../../raw/apps/swmm-icm-knowledge-library.md). Bob uploaded it on 14 November 2026.

**How it was written.** By Claude (Anthropic) under Bob's direction. Bob built the original Replit app (NewsletterGallery) and supplied its source export. The file says most summaries in the library "came from the Replit build and are AI-written", and that summaries of added items are Claude's.

**Claims worth keeping**
- Records in this build, by collection: 66 newsletter editions; 163 LinkedIn articles; 71 posts; 89 reposts; 20 documents; 278 app entries (15 featured; gallery entries Replit 85, Lovable 5, Netlify 173); 45 tools; 243 GitHub repositories in five organizations; 64 gists; 145 Blogspot posts; 1,327 swmm5.org posts; 22 Open-Source SWMM group posts.
- Total records counted by the build: 9,964.
- 66 of 66 newsletter dates and 163 of 163 article dates were read from LinkedIn on 10 November 2026.
- 38 articles were added from LinkedIn's list and are not yet summarized; 37 articles listed twice were merged.
- Post and repost dates come from the ID inside the LinkedIn link (`id >> 22` gives milliseconds since 1970), not from a date read off the page.
- Search by exact name: 2,610 of 2,610 titled records came back.
- Each tool card is labeled a code excerpt, a usage example or an outline. "None is labeled a working tool."
- The page's search, related-content and catalog functions give the same results as the original Replit code on the same data.
- v70 adds a link to this repository; v68 added it as a repository record.
- No license is stated for the content.

**Limits it states.** Links other than newsletter and article links have not been re-checked by a person. Repository and gist dates are last updates, not creation dates. Search finds words, not meaning. Its human-review line: "none recorded for this build beyond Robert's own use of the page".
